Peclet number $(\text{Pe})$, named after [Jean Claude Eugene Peclet](jeanPeclet.md) (1793-1857), is a dimensionless number which is very useful in studying different transport phenomena. It is defined as the ratio of diffusive time scale $(\tau_D)$ to advective time scale ($\tau_A$). In a porous medium, diffusive time scale can be written as ($\tau_D = l_0^2/D$) where $D$ is the diffusion constant of the reactive fluid. Then, $\text{Pe}$ can be written as following:
$$\text{Pe} = \frac{\tau_D}{\tau_A} = \frac{v_0 l_0}{D}$$
For larger length scales ($\text{Pe} \gg 1$), flow in the system is naturally advection-dominated, while for smaller $l_0$,  $\text{Pe}$ is $\ll1$; therefore, diffusion dominates the transport phenomenon.
