# Notebooks

These are the personal notes of **Rishabh P. Sharma**, published at
[notes.rishabhps.com](https://notes.rishabhps.com). The format is inspired by
Cosma Shalizi's [notebooks](http://bactra.org/notebooks/): a collection of things
I found worth keeping, from philosophy and history to physics and pattern formation.

## Use of AI

- **Notes:** written by me. The text of the notes is not generated by AI.
- **Site code:** the code that builds the site (templates, styles, the markdown
  plugins in `src/utils/`, and the deployment workflow) was developed with the help
  of [Claude](https://www.anthropic.com/claude) through Claude Code, an AI coding
  assistant, from October 2026 onwards. I directed the design and reviewed the
  changes. Commits made with its help say so with a `Co-Authored-By: Claude` line.
